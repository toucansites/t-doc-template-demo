# Changing the site title

The **site title** is a key piece of information for branding, identification and SEO. In **T-Doc Template**, the **site title** is 'T-Doc'.
You can change it in a second.

Open the **site.yaml** file in your project directory.
This file contains the global configuration for your site, including the site title, navigation and footer content.

Change the **site title** according to your needs.
[Regenerate the site automatically](/getting-started/03-how-to-use#how-to-regenerate-the-site) and refresh your browser.
